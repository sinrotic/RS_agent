# 历史归档说明

本目录保存历史实验报告、旧数据画像、旧阶段材料和过时计划，只作为证据追溯使用。

## 使用边界

- 本目录不作为当前模型路线、Agent 规划或阶段计划的主入口。
- 当前方案以 `dic/README.md`、`dic/PROJECT_STRUCTURE.md`、`dic/architecture/`、`dic/phases/` 和 `dic/experiments/` 为准。
- 如果历史材料中的判断与当前文档冲突，以当前文档和最新可复现实验结果为准。
- 不确定是否仍有效的旧材料，先保留在归档区，不直接纳入当前规划。

## 建议分区

后续如继续细化归档，可按以下方向整理：

- `experiment_reports/`：历史实验报告。
- `data_profiles/`：历史数据画像。
- `obsolete_plans/`：已被当前方案替代的旧计划。
- `uncategorized/`：暂时无法判断归属但需要保留的材料。
