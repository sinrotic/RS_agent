# 首页与对话复用已训练 COLD / DeepFM 排序

延续原 COLD→DeepFM 主排序决策，将现有训练参数接入 Java 首页和对话候选排序，并从原始 train 正向事件构建训练结束时的只读特征快照，避免把全时段画像统计误当作训练可见特征。模型仅使用六个历史统计特征，因此明确查询保留 BGE 相关性融合和偏好、多样性处理；模型运行时故障回退并记录降级，已有候选重排不得重新召回替换候选池。

本次是用户授权的工程接入，保留原产物的诊断标记和效果门禁，不能据此宣称推荐效果或 CTR 提升；静态特征更新及模型再训练仍需独立评估与版本发布。详见 [部署与验证记录](../superpowers/2026-09-13-trained-ranking-serving.md)。
