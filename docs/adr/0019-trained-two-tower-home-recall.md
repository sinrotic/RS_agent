# ADR-0019：训练双塔进入首页召回

状态：已接受，2026-09-13。用户明确要求接入已训练双塔，因此更新 ADR-0018 中首页不接入双塔的范围决定：首页增加真实 epoch 5 YouTubeDNN 召回，保留 BGE 排序、Catalog 商品事实、探索和交付去重。原实验 pool500 的诊断状态保留；新增独立 serving manifest 只授权本次 Java 首页路由，不代表原实验全量晋级。

查询使用仓库既有 queryv2 路径：最近正向历史的归一化商品向量按时间衰减聚合，经过训练好的用户塔 MLP 和残差，再归一化。导出产物只有归一化商品向量，因此不宣称它与原训练原始嵌入前向或离线预计算用户向量等价，原离线指标不能直接沿用。64 维双塔使用独立 Milvus 集合，不与 1024 维 BGE 混用。

Recommend 通过专用 CPU HTTP 运行时获取用户向量；缓存按模型、画像和有序历史隔离，最多 5000 项、10 分钟过期。历史不足或词表外历史走其他召回；运行时故障显式降级。双塔候选参与融合与 BGE 排序，不强制每页展示；喜欢后找相似继续以明确喜欢的商品为中心。通过配置开关可退出本路由。

实施、证据与回滚见 [接入记录](../superpowers/plans/2026-09-13-two-tower-home-integration.md)。
