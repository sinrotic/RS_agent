# ADR-0018：首页个性化召回与交付去重

2026-09-13：用户授权将训练双塔加入首页；关于“不晋级双塔”的首页范围由 [ADR-0019](0019-trained-two-tower-home-recall.md) 更新，原 pool500 离线实验状态不变。

- 状态：已接受
- 日期：2026-09-07

首页使用认证账号绑定的 Profile User，从 User 服务读取最近的正向评价商品，经 Catalog 回填得到兴趣种子。最近的明确喜欢优先于历史兴趣，已明确不喜欢的历史商品不再作为查询种子。

候选由画像／反馈语义召回、真实 Catalog 类目召回、跨类目探索共同组成。语义召回使用现有 `rs_agent_semantic_items_bge_m3_v1` 索引（1024 维、COSINE），只以 ID 召回，商品事实仍以 Catalog 为准。索引覆盖不完整，因此类目召回是必要的补充。此变更不晋级双塔或实验 pool500 产物。

首页以 BGE reranker 的真实归一分数排序，再施加有界的明确反馈调整；类目和品牌保护保留替代选择，停产、日期、包装尺寸等通用元数据不自动成为兴趣证据。缺少候选多样性时允许补满页面，不凭空生成商品。

近期去重从持久 Recommendation Delivery 和真实曝光事件读取，按 Profile User 跨 Session 生效，窗口为 24 小时，每个来源最多读取 2000 条。交付即临时排除，避免曝光上传延迟造成连续重复；这不等价于把交付记录当作真实曝光事件。

`feed:<request_id>` 表示换个方向，排除已交付商品后重新召回；`similar:<request_id>` 表示喜欢后找相似；`rerank:<request_id>` 允许当前交付中的商品继续参与反馈重排。三类游标必须属于同一账号、画像和会话，且交付未过期。游标不再代表商品 ID 的数据库分页位置。

2026-09-08 补充：真实商品存在跨类目标记的同款变体，单纯 ID 和类目计数不足以衡量换批。首页从近期交付与曝光各最多 36 条 ID 回填商品内容，并合并游标上一批；除已交付 ID 外，通过品牌与型号、足够长标题的高相似度排除同款。换批优先选择与上一批内容差异更大的已有兴趣作为模型排序查询，避免始终使用第一个兴趣。

初始页预留 25%、换批预留 50% 的真实 Catalog 探索席位，向上取整；六项页面分别为 2 和 3 席。只有真实探索来源能够占用该份额，不能把没有偏好加分的语义候选计为探索。选择时同时考虑模型分数、与近期内容及本页内容的相似度，并保留首屏类目最多 4、品牌最多 3 的保护；备选不足时可放宽品牌／类目约束，但不重新填入识别出的同款。找相似保留当前兴趣、不强制探索席位。内容去重后无结果返回可重试错误，不声称整个目录已浏览完。

标题规则是可解释的内容启发式，不是通用视觉商品识别。图片未直接参与后端去重；真实回放另行比较主图，以验证本次同图尺寸变体不再重复。复现和结果见 [2026-09-08 修复记录](../superpowers/plans/2026-09-08-home-refresh-content-diversity.md)。

当前部署只有一个 Recommend 实例，在该实例内串行化同画像的生成与交付写入，保证并发请求不会读取相同的旧交付集合。水平扩展前必须增加数据库或带 fencing 的跨实例协调，不能仅增加副本数。

模型、历史或召回故障在响应中通过 `recommendation_mode` 和 `degradation_reasons` 表达；前端显示降级提示。Trace 记录实际候选数、模型排序数和召回来源，Micrometer 记录延迟、候选数量、类目覆盖与降级原因。

路由验收证据见 [实施与验收记录](../superpowers/plans/2026-09-07-personalized-home-completion.md)。指标验证的是当前路由行为与有限样本质量，不构成 CTR 提升或训练模型已经完成的声明。
