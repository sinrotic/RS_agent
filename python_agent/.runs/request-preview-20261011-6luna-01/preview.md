# 同模型购物请求样本预览

本批使用服务中的实际模型名 `gpt-6-luna`，生成、需求提取和审核分别使用新的上下文。8 次生成中有 7 条可用顾客原话，另一次返回未通过 JSON 解析。主流程调用模型 21 次，补看审核输出 3 次；补充诊断是新调用，不是恢复原响应，也不改变原隔离结论。

这些是基于真实目录商品和历史正向评价的合成请求，不是真人对话。假想设备、朋友和用途是场景设定，不是从历史证明的事实。所有候选均未加入正式评测集，没有人工批准，也没有上线。

模型的语义判断与程序的协议校验是两回事。本批 8 个候选位置全部保持隔离，不代表 7 条原话都不自然：其中有生成或提取格式错误、审核字段格式错误，也有实际的需求理解问题。同模型审核不构成独立质量金标准。

## 无线适配器和近似预算

顾客原话：

> 家里台式机的无线网卡不太稳定，想换个USB Wi‑Fi适配器，最好支持双频。主要是Windows 11用，预算三十左右，有合适的吗？

模型提取的硬条件是 USB Wi‑Fi 适配器、用于 Windows 11、价格不超过 30。其中价格证据为“预算三十左右”。双频被列为软偏好；币种和购买对象保留为未知，没有提出必要澄清问题。

补充审核认为表达自然、事实边界和澄清策略合理，但需求提取不忠实：“三十左右”不是严格的价格上限，不应直接转换成 `price <= 30`。审核还指出不必把购买者身份当作当前必须澄清的信息。

程序校验仍未通过：审核把 `reason` 输出成分维度对象，协议要求一个字符串。上述判断是原始模型输出的摘要，不是已批准标签。

## 无线适配器和安装便利

顾客原话：

> 家里有台台式机放在路由器旁边不太方便拉网线，最近无线连接也不太稳定，想添个 USB 网络适配器改善一下。比起追求特别高的速度，我更在意安装别太折腾、日常用着可靠；电脑是 Windows，但具体接口和兼容要求我还得确认。能帮我看看哪种更合适吗？

模型提取的硬条件是 USB 网络适配器、用于 Windows、数量恰为 1。软偏好是安装便利、可靠性优先，以及不优先追求极高速度。未知信息为可用接口和具体兼容要求。

提取模型建议问“电脑有哪些可用的 USB 接口？”和“你的 Windows 版本或其他兼容要求是什么？”

补充审核认可自然性、事实边界及相关追问，但认为把“想添个”精确化为数量恰为 1 依据不足。这个数量判断存在讨论空间，仍需人审，而不是因为审核模型这样说就认定提取必错。速度的相对优先级也不能升级为硬性限制。

程序校验仍未通过：审核的 `reason` 为对象而不是字符串。

## 给朋友选通勤耳机

顾客原话：

> 想给朋友挑一副头戴式耳机当礼物，她平时通勤时想少受周围噪声影响，也会用来听音乐和接电话。希望戴久了别太夹耳，预算不用卡得特别死；无线款优先，不过续航和降噪效果我不太会看，有什么合适的选择吗？

模型提取的硬条件是头戴式耳机、数量 1。软偏好为减少通勤噪声、听音乐和接电话、佩戴舒适，以及无线优先。具体预算、续航和降噪标准保留为未知；购买对象识别为他人，没有安排必要追问。

补充审核的自然性、提取忠实度、事实边界、澄清策略四项判断均为通过。审核认为已有信息足以先给合理参考，不必先追问所有未知数值，也不能将赠送者的历史迁移为朋友的偏好。

这只是模型的通过判断。程序校验未通过，因为 `reason` 为对象；候选仍隔离，不能写成“已经验收合格”。

## 显卡水冷的兼容核对

顾客原话：

> 我最近想给显卡改用一体式水冷，主要担心显存和供电区域温度太高。看到有显卡水冷安装架，但不确定它能不能配我手头的冷排和显卡；我该先核对哪些型号和尺寸？

模型提取的硬条件是显卡一体式水冷安装架。软需求是改善显存和供电区域温度；未知包括显卡型号及尺寸、冷排型号及尺寸、相关区域的散热覆盖。

提取模型建议询问显卡品牌型号及尺寸或 PCB 信息，以及冷排型号和尺寸。

本次审核通过程序协议校验，但语义审核判定提取忠实度与澄清策略失败：顾客问的是“该核对什么”，没有要求立即购买安装架；提取把提及的商品升格成必须购买的类型，收窄了意图。审核还认为需要考虑一体式水冷本体的具体型号，不能只问冷排尺寸就保证兼容。

自然性和事实边界的模型判断为通过。候选保持隔离。
